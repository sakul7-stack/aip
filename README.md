# Image and Video Feature Extraction

This project extracts numerical features from one image and one video.

## Run

Open `final.ipynb` in Jupyter with `final.png` and `video.mp4` in the same folder.

## Methods

- **PCA:** image compression and reconstruction
- **Canny:** edge detection and a 4×4 edge-density vector
- **ResNet18:** pretrained 512-value image feature
- **Frame differencing:** video motion density over time
