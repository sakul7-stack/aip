# Image and Video Feature Extraction

A beginner-friendly computer-vision project that represents an image and a video with useful numerical features.

## Run

Open `final.ipynb` in Jupyter and run the cells with `final.png` and `video.mp4` in the same folder.

## Methods

- **PCA:** compact image representation and reconstruction
- **Canny:** image edges and a 4×4 edge-density feature vector
- **ResNet18:** pretrained 512-value image feature
- **Frame differencing:** video motion density over time

The project also includes `feature_extraction_presentation.pptx` and `requirements.txt`.
